# Cybersecurity Lab — Linux Security

## Sobre o projeto

Projeto prático desenvolvido para estudar e aplicar fundamentos de segurança cibernética em um sistema Linux.

## Principais conhecimentos aplicados

- Linux e linha de comando
- Redes e protocolos
- Análise de portas
- Identificação de serviços
- Firewall UFW
- Nmap
- CUPS
- Avahi/mDNS
- Gerenciamento de serviços
- Atualização e manutenção do sistema
- Documentação de evidências

## Resultado

Foi realizada uma avaliação da superfície de exposição do sistema, seguida da aplicação de atualizações e da documentação das configurações e resultados encontrados.

Todas as atividades foram realizadas no próprio sistema Linux utilizado no laboratório.

## Evidências

As evidências estão organizadas nas pastas:

- `configuracoes/`
- `scans/`
- `relatorio/`

## Conclusão

O projeto demonstra a aplicação prática de conceitos de administração Linux, redes e fundamentos de segurança cibernética.
